## Question 1
Evaluate $\frac{a^3+b^3}{c^2+d^2}$ where $a=2$, $b=-2$, $c=4$, and $d=-2$. <br> 
(A) $\frac{4}{5}$ <br>
(B) $\frac{4}{3}$ <br>
(C) $\frac{3}{4}$ <br>
(D) $\frac{5}{4}$ <br>
(E) $0$ <br>
(F) None of the above

### Answer
```math
\begin{flalign*}
\frac{a^3+b^3}{c^2+d^2} &= \frac{2^3 + (-2)^3}{4^2 + (-2)^2} &&\\
&= \frac{8 - 8}{16 + 4} &&\\
&= \frac{0}{20} &&\\
&= 0 &&
\end{flalign*}
```

Therefore, E.
