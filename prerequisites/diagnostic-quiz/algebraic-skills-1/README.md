# Algebraic Skills I

## Question 1

Evaluate $\frac{a^3+b^3}{c^2+d^2}$ where $a=2$, $b=-2$, $c=4$, and $d=-2$.

- (A) $\frac{4}{5}$
- (B) $\frac{4}{3}$
- (C) $\frac{3}{4}$
- (D) $\frac{5}{4}$
- (E) $0$
- (F) None of the above

<details>
  <summary><strong>Solution</strong></summary>

  ```text
  (a^3 + b^3) / (c^2 + d^2)
  = (2^3 + (-2)^3) / (4^2 + (-2)^2)
  = (8 - 8) / (16 + 4)
  = 0 / 20
  = 0
  ```

  Therefore, option E.
</details>
